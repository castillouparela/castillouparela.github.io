¿Qué es la Ingesta de Datos?

Proceso de recopilar, importar y preparar datos desde diversas fuentes para su análisis y procesamiento.

  • Extracción de datos
  • Transformación
  • Carga (ETL)

SQL para Ingesta de Datos

Comandos Principales

-- Crear tabla
CREATE TABLE datos_ingesta (
    id INT PRIMARY KEY,
    nombre VARCHAR(100),
    fecha_ingesta DATE,
    valor DECIMAL(10,2)
);

-- Insertar datos
INSERT INTO datos_ingesta VALUES
(1, 'Dato 1', '2024-01-01', 100.50),
(2, 'Dato 2', '2024-01-02', 200.75);

-- Consultar datos
SELECT * FROM datos_ingesta;
