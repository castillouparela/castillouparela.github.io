¿Qué es EDA?

Proceso de analizar y visualizar datos para entender su estructura, patrones y características principales.

  • Entender la distribución de variables
  • Identificar outliers
  • Descubrir correlaciones
  • Preparar datos para modelado

Herramientas para EDA

Python con Pandas y Matplotlib

import pandas as pd
import matplotlib.pyplot as plt

# Cargar datos
df = pd.read_csv('datos.csv')

# Estadísticas descriptivas
print(df.describe())

# Visualización
plt.hist(df['columna'])
plt.show()
